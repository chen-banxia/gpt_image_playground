# 图片分组

- 顶部“管理分组”可新建、重命名、删除分组，名称最多 40 字且不能重复。
- 顶部分组选择框可与搜索、状态、收藏筛选同时使用。“全部分组”显示全部记录，“未分组”包括旧版本记录。
- 每张任务卡片和详情中都有分组选择框；同一生成任务的多张成品属于同组。
- 开启批量操作，选中记录后选择“移动到分组”。画廊每页 9 条，全选仅针对当前页；翻页、切换筛选或移动记录会清除相关选中项。
- 在具体分组下新建生成任务，记录归入该组；在“全部分组”或“未分组”下提交时归入未分组。顶部会显示当前新任务归属。
- 提交时即固定任务分组，处理参考图或等待响应期间切换分组不会改变归属，不会中断请求。任务完成仍写回原分组。
- 正在生成的记录也可以移动分组；只修改归属，不重新发请求、不覆盖任务状态和输出。重试和铺满副本继承来源记录的现有分组。
- 删除分组需要确认，只将其记录归入未分组；图片、任务和进行中的请求保留。
- 分组列表保存在浏览器本地，任务归属保存在 IndexedDB。备份包含分组，导入时同名分组合并，冲突 ID 会重建；旧备份没有分组时归入未分组。

分组是记录的整理方式，不是独立账号、接口或任务队列；各组共享既有 API 配置及并发机制。
