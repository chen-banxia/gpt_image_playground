# 视频工作台测试记录

- `npm test`：27 个测试文件、235 项测试通过，包含文件下载跨域回退与白名单、提交/查询超时、服务路由、H3 原生响应、重试、视频能力、时长、中英文及图片筛选和批量队列测试。
- `npm run build`：TypeScript 检查及 Vite 生产构建通过。
- `tests/video_workbench_browser.py`：完整浏览器流程通过，无页面 JavaScript 异常，390px 手机视口无横向溢出。
- `tests/video_localization_browser.py`：中英实时切换、视频表单、设置、详情、已有提示、五种屏幕宽度通过；图片和视频左侧面板均与作品区顶部操作栏对齐，仍位于导航下方。
- `tests/workspace_toolbar_browser.py`：两边共用工具栏在中英文、六种屏幕宽度下的顺序和高度一致；覆盖下载/模型筛选、部分下载、跳页校验、本页选择及跨工作台图片下载队列。
- `tests/video_provider_retry_browser.py`：验证服务路径编辑、非法路径拒绝、V1 兼容别名持久化、恢复 H3 V2 默认值、旧失败记录快捷重试、草稿不被覆盖及中英文手机端。
- `tests/video_preview_browser.py`：可见卡片自动显示真实视频帧、静音暂停、无 CORS 的跨域预览、离屏释放、失败提示、勾选与详情播放、翻页及手机布局通过。预览不改变下载标记，也不携带网关 Key。
- `tests/video_timeout_browser.py`：默认 600 秒、设置校验与持久化、真实浏览器按短测试时限中断、待确认状态、不自动重发及中英错误提示通过。单元测试使用虚拟时间验证 POST 在 60 秒仍等待、600 秒中断，GET 保持 60 秒，并覆盖响应体超时、外部取消和定时器清理。
- `tests/video_download_cors_browser.py`：直读跨域失败后，经同源文件代理下载真实文件内容和 ZIP；签名查询参数保留、不携带网关 Key、缺代理时显示原链接、不会误标下载，英文与手机布局通过。
- 文件代理集成检查：使用本地受控文件源替代 CDN 目标，验证 Vite 转发原始路径和签名、去除 Authorization/Cookie/额外 Key 头、去除上游 Set-Cookie、拒绝非视频路径及 POST、阻止重定向。未访问用户截图中的真实签名链接。
- 开发视频代理模拟验收：POST 创建和 GET 单任务查询成功保留目标部署子路径；GET 集合、POST 单任务和非视频路径均返回 403。
- `git diff --check`：通过。

## 浏览器覆盖

独立浏览器上下文使用模拟 New API，创建三条任务：豆包纯文本、Seedance 2.5 首尾帧、MiniMax-H3 全能参考。验证了 Doubao 与 H3 各自路径、两组视频 Key、JSON 角色映射及分辨率参数。H3 提交返回 task_id，查询使用 task.status 与 task.content.url。

其他覆盖：配置保存、分组创建、草稿刷新恢复、单视频下载、已下载筛选、批量收藏、三个视频的 ZIP 内容、下载标记、独立数据库、备份不含 Key、可播放 WebM、CDN 请求不携带网关鉴权、图片复制到视频后的清理隔离、每页 15 条、本页全选、翻页取消选择、批量删除及返回图片工作台。

浏览器测试视频由 MediaRecorder 在测试上下文中生成，接口和 CDN 均被测试桩拦截，没有调用付费模型。

## 单元与契约覆盖

五个模型精确识别及 Key 路由、部署子路径、任务 ID 编码、非法根地址、纯文本与素材 content、首尾帧比例约束、参考角色、H3 不支持字段省略、仅 ID 不误判成功、结果 URL 校验、Bearer 与 JSON 请求、错误脱敏和 Retry-After。

存储覆盖：独立数据库、Blob 与元数据落盘、字段补丁不覆盖分组收藏、迟到响应不复活已删记录、两种草稿引用保护、持久化失败不提交、未知 POST 不重发、终态不回退、导入及 Key 轮换需授权、备份类型隔离、组映射、参数与下载标记保留、重复导入去重。

下载覆盖：CDN 无鉴权、拒绝 HTML、无 Content-Length 时仍限制实际体积、逐项成功标记、部分 ZIP 确认后只标记包内成品、取消 ZIP 不误标记。

## 尚未验证的环境项

没有使用真实模型账号执行收费生成。因此当前 New API 部署的五模型权限、H3 插件与渠道配置，以及外部素材地址和 CDN CORS，仍需账号联调。根据公开文档，H3 使用海螺 V2 接口，V1 路径默认面向旧系列。

补充代理验证：Doubao、海螺 V2 和显式配置的 V1 兼容路径，创建 POST 与查询 GET 均正确保留部署前缀；不允许的方法与其他路径返回 403。自定义路由仅允许相对路径，不能把 Key 转发至输入的外部 URL。

本机 Docker Desktop Linux 引擎未运行，未执行容器构建和 Nginx 运行时验证。Docker 配置已增加受限视频代理，开发代理的路径与方法限制已通过模拟验证。

生产构建仍提示单个 JavaScript 包大于 500KB，以及 Browserslist 数据需要更新；这些未阻止构建。当前视频 ZIP 使用 256MB 有界内存方式，未实现无限流式写盘，详见使用说明。
