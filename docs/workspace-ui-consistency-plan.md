# 图片与视频工作台界面统一规划

状态：工具栏、批量栏、分页及面板头部已实施

范围：左侧面板头部及展开收起、作品区标题与筛选、批量操作栏、分页

目标：切换图片和视频时，同一种操作保持相同名称、位置、外观和交互。

## 1 改造前差异

| 区域 | 图片工作台 | 视频工作台 | 统一方向 |
| --- | --- | --- | --- |
| 面板标题 | 画图设置 | 视频创作 | 图片创作 / 视频创作，共用标题样式 |
| 收起按钮 | 收起面板，侧栏图标 | 收起 ‹，字符箭头 | 共用图标与“收起面板”文案 |
| 收起状态 | 展开图标及提示 | 单独 › 字符 | 同一窄栏、展开按钮、提示及键盘焦点 |
| 作品标题 | 缺少独立标题行 | 视频作品与存储说明 | 两边都有标题，存储说明归入帮助提示 |
| 分组 | 单独一行，含新作品归属 | 与所有筛选挤在一起 | 第一行统一放分组与归属提示 |
| 收藏 | 星形图标 | ☆ 仅收藏文字按钮 | 同一星形图标与“仅收藏”文字按钮 |
| 筛选 | 状态与搜索 | 状态、模型、下载与搜索 | 相同控件与位置，补齐图片模型及下载筛选 |
| 批量栏 | 居中深色小工具条 | 全宽边框工具条 | 同一全宽工具条与按钮顺序 |
| 分页 | 跳页输入与跳转按钮 | 只有输入框，回车跳页 | 共用分页组件，按钮和回车一致 |

## 2 左侧创作面板

头部统一为“图片创作”或“视频创作”，右侧使用同一侧栏图标与“收起面板”。英文分别为 Image creation / Video creation；按钮统一为 Collapse panel / Expand panel，不再使用不同长度的 Collapse、Collapse ‹ 等文案。

- 展开时按钮图标、字体、内边距、hover、focus 状态一致，点击高度至少 40px，手机端至少 44px。
- 桌面收起后保留现有 56px 窄栏，同一展开图标；悬停和键盘焦点可读到“展开面板”，屏幕阅读器使用完整标签。
- 手机端收起后显示同一整行展开入口，显示图标和文字。
- 两边默认展开；收起只隐藏内容，提示词、参数、素材和进行中任务保留。
- 保持用户最新确认的位置：两个面板顶部与作品区顶部操作栏对齐，且始终在顶部导航下方，不恢复为第一排作品定位。
- 抽取共用面板头部与定位逻辑，两个表单只负责自己的字段。

## 3 作品区工具栏

桌面统一结构如下。所有行在图片和视频页面使用同一套间距与对齐规则。

```text
图片作品 / 视频作品                                      存储说明 ⓘ

[全部分组（数量） ▾]  管理分组    新作品归入：未分组

[☆ 仅收藏] [全部状态 ▾] [全部模型 ▾] [全部下载状态 ▾]
[搜索描述、模型或参数……………………………………] [批量操作]

〈进入批量或有选中项时显示共用批量工具栏〉

第 1–15 条，共 N 条 · 每页 15 条      上一页  1 / P  下一页  跳至 [1] 页 [跳转]

作品卡片列表
```

筛选组在宽屏可与搜索同排，空间不足时**整组换行**：搜索和批量入口保持在一起，不能只因英文更长就把个别按钮挤到零散位置。两个工作台采用相同断点和布局容器。工具栏顶部与侧栏之间的关系由公共布局计算。

### 3.1 控件与提示

| 项目 | 统一规范 |
| --- | --- |
| 操作控件 | 40px 高、12px 圆角、14px 字号；移动端至少 44px 点击高度 |
| 图标 | 同一套 SVG，建议 16–18px；不混用文本星号、字符箭头和 SVG |
| 间距 | 同组控件 8px，行间 12px，工具栏与分页间 16px |
| 默认与选中 | 中性边框背景；选中使用蓝色主题，收藏选中用同一黄色规则 |
| 下拉菜单 | 共用可键盘操作的选择控件、同一浮层风格；统一 disabled 原因提示 |
| 搜索 | 相同搜索图标、占位符和清空入口，宽度填充剩余空间 |
| 存储说明 | 标题旁帮助入口，打开后说明当前浏览器存储；不在视频工具栏固定占一长行 |
| 空列表 | 仍显示标题和工具栏，分页统一为 0 条、1 / 1、前后页禁用 |

### 3.2 筛选内容保持业务准确

状态筛选的共同文案为“全部状态、生成中、已完成、失败”；视频可额外提供“排队中、待同步”等必要状态，控件位置不变。内部图片 done / error 与视频 succeeded / failed 不必为了统一 UI 而改写存储数据，由页面适配为显示选项。

图片补齐“模型”和“下载状态”筛选，以实际历史中的模型标识和下载信息为依据，缺少模型信息的历史显示“未知模型”。视频仍使用已有的五模型范围与历史元数据。

下载选项统一为“全部下载状态、未下载、部分下载、已下载”。图片多图记录按成品数量计算；视频首版单产物不会出现部分下载记录，但不需要为此改变筛选栏布局。无产物记录不属于未下载或已下载；图片下载判定继续读取原图片标记，视频读取独立视频记录。

分组显示当前工作台的记录数量。选择具体分组时，新作品默认归入该分组；视频若在左侧手动指定另一个分组，工具栏显示**实际草稿的目标分组**，不能继续显示筛选分组造成误解。全部分组或未分组的默认归属为未分组。

## 4 批量工具栏

统一采用列表上方的全宽圆角区域，背景随明暗主题变化，左对齐排列；不悬浮覆盖卡片，也不依附左侧输入面板。

```text
已选 N 条 · 可下载 M 个文件
[全选本页 / 取消全选] [移至分组 ▾] [收藏 / 取消收藏]
[下载 ▾] [删除记录]                                    [退出批量]
```

- 数量统一使用“条记录 / 个文件”，避免图片数量和视频数量造成工具条长短跳动。
- “下载”统一菜单内提供“打包 ZIP”“逐项下载”和“仅下载未下载文件”的范围选项。图片目前缺少的逐项队列需要接入其现有下载函数；视频沿用既有队列，不将两类文件混装进一个下载状态。
- 图片的批量 ZIP 能力保留为明确选项，不能因为统一菜单而消失；菜单中直接显示两个操作名称，选择后执行，不强迫用户先打开详情。
- 收藏操作名称随选择变化：全部已收藏时显示“取消收藏”，否则“收藏”，不用“收藏/取消收藏”这个含义不明确的单一标签。
- 删除使用危险色，其他按钮保持同一中性或主色规则；按钮禁用时显示原因。
- “批量操作 / 退出批量”作为一致的一对文案，中文不再一处显示“完成”、另一处显示“退出批量”；英文统一 Batch actions / Exit selection。
- 两边均只全选当前筛选后的本页，翻页、筛选或跨工作台切换清除选择。切换工作台不取消已开始的下载队列。
- 批量结果保留记录类型的必要说明：删除本地视频不会取消远端任务；不能为了文案一致省去这一事实。

## 5 分页与响应式

两边使用同一个受控分页组件，输入 currentPage、totalPages、total、start、end 和 onPageChange，不由分页组件直接访问图片 store。每页固定 15 条，跳页同时支持按钮与回车，校验整数和范围。

手机布局统一：标题一行；分组和管理入口一组，归属说明可另起一行；筛选控件两列排列；搜索与批量入口同组；分页按空间换行。英文按钮允许适度增宽或组内换行，不缩字号、不裁掉关键操作、不产生横向滚动。

批量工具栏只在进入批量或存在选择时出现，两边一致。显示和隐藏可以改变列表起点，但左侧面板仍使用相同的定位规则，不出现图片页和视频页不同的位移算法。

## 7 验收标准

- 两个面板都显示“收起面板”，收起后均为同一“展开面板”入口，图标、尺寸、hover、focus 与英文一致。
- 两个作品区的标题、分组、收藏、状态、模型、下载、搜索和批量入口顺序一致；相同视口下使用相同换行规则。
- 进入批量后按钮顺序、样式、数量摘要一致；全选只限本页，退出和切换工作台无隐藏残留选择。
- 图片多产物的部分下载判定正确，视频无成品不混入未下载；URL 更新不改变视频已有下载标记。
- 批量下载菜单内能找到 ZIP 和逐项下载；失败、取消、部分成功不误标记全部完成。
- 同一分页组件处理按钮、回车跳页、输入非法页码、删除末页和空结果，两边均每页 15 条。
- 中英文即时切换无残留公共文案，用户输入和文件名不被翻译；320、390、768、1024、1440px 下无横向溢出。
- 面板与作品顶部操作栏对齐，导航不遮挡按钮；收起、筛选、批量与语言切换后位置保持有效。
- 图片生成、视频提交/查询、两库清理隔离与下载队列原行为通过回归。

工具栏、批量栏和面板头部位于 `src/components/workspace/`，分页复用受控的 `GalleryPagination`。图片逐项下载使用独立于页面的队列，切换到视频页后继续执行，成功项才写入图片下载标记。图片与视频存储及下载执行器保持隔离。

`tests/workspace_toolbar_browser.py` 覆盖中英文及 320、390、768、1024、1440、1700px 下的公共控件顺序和工具栏高度、筛选、批量选择、跳页、空列表及跨工作台下载队列。具体功能和交互以当前实现及使用说明为准。
